AegisGen — Project Overview

Research Area

Computational biology, bioinformatics, and antimicrobial resistance.

Research Question

Can k-mer-based features extracted from bacterial genomic sequences provide useful information for predicting antimicrobial resistance phenotypes?

Planned Components

- DNA sequence processing
- k-mer generation
- Trie-based sequence processing
- Feature extraction
- Machine learning
- Model evaluation
- Biological interpretation

Scientific Scope

AegisGen will be developed and evaluated as a research-support tool. Its predictive performance and scientific usefulness must be demonstrated through appropriate experiments and validation.

Development Principle

Learn, implement, test, understand, and document each component.
