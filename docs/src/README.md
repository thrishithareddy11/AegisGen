AegisGen Source Code

This directory will contain the Python modules used to build AegisGen.

Planned Modules

- "fasta_parser.py" — read and process DNA sequence files
- "kmer_generator.py" — generate overlapping k-mers
- "trie.py" — implement Trie-based sequence processing
- "feature_extraction.py" — convert sequences into numerical features
- "model.py" — train machine-learning models
- "evaluation.py" — evaluate model performance

These modules will be added incrementally as each component is implemented and tested.
