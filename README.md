AegisGen 🧬

Computational Biology | Bioinformatics | Antimicrobial Resistance

Overview

AegisGen is a computational biology project investigating whether patterns in bacterial DNA sequences can help predict antimicrobial resistance using machine learning.

Planned Workflow

1. Bacterial DNA sequence processing
2. k-mer generation and analysis
3. Trie-based sequence processing
4. Numerical feature extraction
5. Machine-learning model development
6. Model evaluation and biological interpretation

Objective

To investigate whether genomic sequence patterns contain useful information for predicting antimicrobial resistance phenotypes.

Current Status

Project setup and foundational Python implementation.

Disclaimer

AegisGen is intended as a research-support project. Its predictions are not intended to replace laboratory antimicrobial susceptibility testing or clinical decision-making.
